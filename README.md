# 静伴 N-01 · 安宁疗护床旁机器人

一台不陪聊、不碰人、不做生存期预测的床旁机器人。
它只做三件事：记录、按分级把该说的话说给该听的人、以及安静地待在该待的位置。

## 为什么做这件事

人工智能与机器人正在大量替代人工，这个过程不可阻断；但新岗位不会同时出现，失业的人很难马上找到新工作、稳住家庭生活。与此同时，医院里有一段时间是空的：白天查房、交班、家属、社工把人围满，夜里全都退场，人是按班次来的，症状却是连续变化的。

这台机器人不是为了替代医护和家属，而是补上那段没人能 24 小时守着的空白。它做得很安静，因为在那段时间里，病人可能一句话不说，也可能说个不停，或者暴躁、伤感——他需要的不是对话，是旁边有个人。

## 它做什么、不做什么

| 做 | 不做 |
|---|---|
| 记录呼吸、体动、离床等基础数据 | 不陪聊，不做情感陪伴式对话 |
| 按 L1–L4 分级把信息送到对应的人（屏显 / 出声 / 报房号 / 报护士位置） | 不碰人：没有手臂，只有圆形肩块 |
| 在医护已标记濒死期时保持静默 | 不做生存期预测，不给「还剩多久」的数字 |
| 位置纪律：进门 3 秒内让开、屏压暗 | 不在床边充电 |

## 三个点位

- **P1 床旁主位**：床尾左前 0.9 m，距床沿 0.6 m。躺着的病人能看清正面，又不挡护理操作；不站床头，因为那是护士扎针、翻身最常去的地方。
- **P2 窗下退让位**：人一进门，3 秒内让到 0.5 m 外的窗下。不是礼貌，是纪律。
- **P3 护士站侧墙充电位**：不在床边充电。线缆会绊人；从床边充完电再推去另一张床，等于跨床带菌。

平面示意见 `visual/P-三个点位平面图.png`。

## 关键尺寸与硬限制

- 整机高 1.15 m，头径 0.28 m，底盘宽 0.40 m，屏心离地 0.95 m
- 32 个自由度只用四处：头转、屏亮、底盘移动、灯带变色
- 夜间移动 0.30 m/s，日间 0.60 m/s；夜间噪声 ≤ 42 dB(A) @ 1 m
- 门净宽 0.9 m 起，过槛 ≤ 15 mm；熄灯后病房 0.5–1 lx，走廊约 5 lx
- 台词上限 8 字；唯一一句 12 字句：「十点抽血，两点医生查房」；危机时只说「我叫护士。」
